# スマホ対応工程表アプリの確認方法

このリポジトリは `index.html` 単体で動作するシングルページアプリです。ブラウザで表示するだけで全ての機能（公開ビュー／管理ビューの切り替え、期間表示の切り替え、ズーム、ドラッグによる工程変更、依存関係の追従、実線／破線切り替え、Excelダウンロードなど）を試せます。

## 確認手順

1. リポジトリをクローンするか ZIP を展開します。
2. 任意のローカル HTTP サーバーを起動します。Python がインストールされている場合は以下のコマンドで簡単に立ち上げられます。

   ```bash
   python3 -m http.server 8000
   ```

3. ブラウザで `http://localhost:8000/index.html` にアクセスします。
4. スマートフォンの場合は同一ネットワーク上の端末から `http://<PCのIPアドレス>:8000/index.html` にアクセスしてください。

ローカル HTTP サーバーを使わず、`index.html` をダブルクリックしてブラウザで直接開くこともできますが、ブラウザによってはローカルファイルアクセスの制限で一部機能が動作しない場合があります。そのため HTTP サーバー経由での確認を推奨します。

## 補足

- Excel 形式のダウンロード（`Excel (.xlsx)` ボタン）はブラウザ上で完結します。サーバー側の処理は不要です。
- 入力内容の記憶にはブラウザの LocalStorage を利用しています。同一ブラウザ・同一端末内でのみ有効です。
- 休日設定は `index.html` 内の `HOLIDAYS` 配列で管理しています。必要に応じて編集してください。

以上の手順でアプリの挙動を確認できます。
